# 刘晓艳语法体系与长难句拆解

## 一、英语句子的根基

### 什么是句子

英语句子必须具备主谓结构。主语是谓语动作的发出者，谓语必须有时态。
一个简单句有且仅有一个有时态的动词。

**五类基本句型:**

| 类型 | 结构 | 例句 |
|------|------|------|
| 主谓(SV) | S + Vi | Birds fly. |
| 主谓宾(SVO) | S + Vt + O | I love English. |
| 主谓双宾(SVOO) | S + Vt + Oi + Od | He gave me a book. |
| 主谓宾补(SVOC) | S + Vt + O + C | They made me happy. |
| 主系表(SLP) | S + LinkV + P | She is a teacher. |

### 谓语动词的时态

| 时态 | 构成 | 用法 |
|------|------|------|
| 一般现在 | do/does | 经常性动作、客观事实 |
| 一般过去 | did | 过去发生的动作 |
| 一般将来 | will do | 将来发生的动作 |
| 现在完成 | have/has done | 过去动作对现在的影响 |
| 过去完成 | had done | 过去某一时间之前完成的动作 |
| 现在进行 | am/is/are doing | 正在进行的动作 |
| 过去进行 | was/were doing | 过去某一时刻正在进行的动作 |

## 二、从句体系

### 名词性从句(把句子当名词用)

**主语从句:**
- That he passed the exam surprised everyone.
- Whether we will go depends on the weather.
- What you said is true.

**宾语从句:**
- I know (that) you are right.
- I wonder whether/if he will come.
- Tell me what you want.

**表语从句:**
- The problem is that we don't have enough time.
- This is what I mean.

**同位语从句:**
- The fact that he lied surprised me.
- There is no doubt that he is qualified.

晓艳提醒：同位语从句前面一定是抽象名词(fact/news/idea/doubt/hope/belief...)

### 定语从句(修饰名词的从句)

**关系词选择:**

| 先行词 | 主语 | 宾语 | 定语 |
|--------|------|------|------|
| 人 | who/that | who/whom/that | whose |
| 物 | which/that | which/that | whose/of which |
| 时间 | when | when | - |
| 地点 | where | where | - |
| 原因 | why | why | - |

**限制性 vs 非限制性:**
- 限制性：The book which/that I bought is interesting.(无逗号)
- 非限制性：The book, which I bought yesterday, is interesting.(有逗号，不能用that)

晓艳提醒：介词+which/whom 是考点！如 in which, for whom, on which...

### 状语从句

| 类型 | 常见连词 |
|------|----------|
| 时间 | when, while, as, before, after, since, until, as soon as |
| 原因 | because, since, as, now that, in that |
| 条件 | if, unless, as long as, provided that |
| 让步 | although, though, even though, while, whereas |
| 目的 | so that, in order that, lest |
| 结果 | so...that, such...that |
| 比较 | than, as...as, the more...the more |

## 三、长难句拆解三步法

### 实战示范

**真题例句:**
The fact that such a large number of college graduates are unable to find a job has become a social problem that cannot be ignored.

**Step 1: 找主干**
- 主语：The fact
- 谓语：has become
- 宾语：a social problem
- 主干：The fact has become a social problem.

**Step 2: 剥修饰**
- that such a large number of college graduates are unable to find a job -> 同位语从句修饰 The fact
- that cannot be ignored -> 定语从句修饰 a social problem

**Step 3: 理逻辑**
- 一个事实变成了一个社会问题
- 什么事实？大量大学毕业生找不到工作
- 什么样的问题？不可忽视的问题

**完整翻译:**
大量大学毕业生找不到工作这一事实，已经成为一个不可忽视的社会问题。

### 拆解原则

1. 一个句子有多少个有时态的动词，就有多少个分句
2. 并列连词(and/but/or)连接的是并列分句
3. 从属连词(that/which/when/if等)引导的是从句
4. 分词结构(-ing/-ed)和不定式(to do)是短语，不是从句

## 四、常见语法错误

1. 双谓语错误：一个简单句只能有一个有时态的谓语
2. 主谓不一致
3. 悬垂分词
4. 从句残缺：The reason is that... 不能说 The reason is because...
